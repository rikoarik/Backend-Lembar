## LIST ACCOUNTS (server-side search + filter + pagination)
--------------------------------------------------------------------
GET /v1/admin/accounts

  Auth: superadmin JWT
  Query params:
    ?q=guru          — search email/name/username (case-insensitive)
    ?role=teacher    — filter role: teacher | school_admin | superadmin | subscriber
    ?status=aktif    — filter: aktif | baru | ditangguhkan
    ?page=1          — halaman (default: 1)
    ?limit=50        — per halaman, max 100 (default: 50)

  Response 200:
  {
    "data": [
      {
        "id": "uuid",
        "email": "budi@sdncontoh.sch.id",
        "name": "Budi Santoso",
        "displayName": "Budi Santoso",
        "username": "budi",
        "role": "teacher",
        "roles": ["teacher"],
        "status": "aktif",
        "school": "SDN Contoh 01",
        "workspaceId": "uuid",
        "createdAt": "2026-07-25T09:00:00Z"
      }
    ],
    "meta": {
      "total": 140,
      "page": 1,
      "limit": 50,
      "pages": 3
    }
  }

## INVITE ACCOUNT
--------------------------------------------------------------------
POST /v1/admin/accounts/invite

  Auth: superadmin JWT
  Body:
  {
    "email": "guru@sekolah.sch.id",   // required
    "name": "Nama Guru",              // optional
    "role": "teacher"                 // optional, default: subscriber
  }

  Response 201:
  {
    "data": {
      "email": "guru@sekolah.sch.id",
      "invited": true
    }
  }

  Error 409: { "error": { "code": "CONFLICT", "message": "Email sudah terdaftar" } }
  Error 400: { "error": { "code": "VALIDATION_FAILED", "message": "email required" } }


## UPDATE ROLES
--------------------------------------------------------------------
PATCH /v1/admin/accounts/:id/roles

  Auth: superadmin JWT
  Body:
  {
    "roles": ["teacher", "school_admin"]   // array of roles
  }

  Response 200:
  {
    "data": {
      "id": "uuid",
      "roles": ["teacher", "school_admin"]
    }
  }

## IMPERSONATE ACCOUNT
--------------------------------------------------------------------
POST /v1/admin/accounts/:id/impersonate

  Auth: superadmin JWT
  Body: none

  Response 200:
  {
    "data": {
      "token": "eyJhbG...",
      "targetId": "uuid",
      "targetEmail": "guru@sekolah.sch.id",
      "targetName": "Budi Santoso",
      "expiresIn": 3600,
      "note": "Token berlaku 1 jam."
    }
  }

  Cara pakai token:
    Authorization: Bearer <token dari response>
  Token sudah berisi: userId, email, roles, workspaceId, impersonatedBy

  Error 404: Account not found
  Error 500: DB unavailable


## DELETE ACCOUNT
--------------------------------------------------------------------
DELETE /v1/admin/accounts/:id

  Auth: superadmin JWT
  Body: none

  Response 200:
  {
    "data": {
      "id": "uuid",
      "deleted": true,
      "email": "guru@sekolah.sch.id"
    }
  }

  Error 400: Tidak bisa hapus akun sendiri
  Error 403: Tidak bisa hapus akun superadmin
  Error 404: Account not found


## BULK SUSPEND
--------------------------------------------------------------------
POST /v1/admin/accounts/bulk/suspend

  Auth: superadmin JWT
  Body:
  {
    "ids": ["uuid-1", "uuid-2", "uuid-3"]
  }

  Response 200:
  {
    "data": {
      "results": [
        { "id": "uuid-1", "success": true },
        { "id": "uuid-2", "success": false, "error": "Not found" }
      ],
      "succeeded": 1,
      "failed": 1
    }
  }

  Catatan: partial success didukung — tidak berhenti jika 1 item gagal

## BULK DELETE
--------------------------------------------------------------------
POST /v1/admin/accounts/bulk/delete

  Auth: superadmin JWT
  Body:
  {
    "ids": ["uuid-1", "uuid-2", "uuid-3"]
  }

  Response 200:
  {
    "data": {
      "results": [
        { "id": "uuid-1", "success": true },
        { "id": "uuid-2", "success": false, "error": "Tidak bisa hapus superadmin" },
        { "id": "uuid-3", "success": false, "error": "Tidak bisa hapus akun sendiri" }
      ],
      "succeeded": 1,
      "failed": 2
    }
  }

  Guards per item:
    - Skip jika id == actor id sendiri
    - Skip jika target punya role superadmin
    - Semua aksi di-audit ke admin_audit (bulk: true)
