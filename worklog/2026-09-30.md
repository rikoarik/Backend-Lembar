## Symptom (reproduced live before the fix)

`POST /v1/uploads/sources/intake` on `127.0.0.1:4000`:

| body | content-type | before | after |
|---|---|---|---|
| `%PDF-…%%EOF` (216 B) | `application/pdf` | 201 `received` | 201 `received` |
| `hello not a pdf` (15 B) | `application/pdf` | **201 `received`** | **415** `VALIDATION_FAILED` |
| `JUST TEXT`×10 (90 B) | `application/pdf` | **201 `received`** | **415** `VALIDATION_FAILED` |
| `hello` | `text/plain` | 415 (fixed in BUG-18) | 415 |
| empty | `application/pdf` | 400 | 400 |

Then `POST /v1/uploads/sources/{id}/verify` on the 15-byte text upload:

- before: **200** `{"status":"verified","magicSignature":"ddbf4b60…"}`
- after: **415** `VALIDATION_FAILED`, DB row `rejected` / `not_a_pdf`,
  audit row `magic_check` / `success=false` / `not_a_pdf`

## Root cause

Two independent holes, both "the header is not the file":

1. `intake` validated only `content-type`, which the client controls. No magic
   bytes were read.
2. `verify` compared `storage.headObject().checksumSha256` against the stored
   version hash. That proves the object is *the one we stored*, not that it is
   a PDF — so any bytes promoted to `verified`.

## Patch

- `src/modules/uploads/domain/SourceUploadsService.ts`
  - `intake`: reject a body not starting with `%PDF-` with an enveloped 415
    **before** `storage.putObject`, so nothing is persisted. Failed attempt
    audited with `failureCode: not_a_pdf` and `uploadId: null`.
  - new `isPdfPayload()` = `looksLikePdfMagic() && hasPdfTrailer()`.
  - `verify`: `storage.getObject()` the payload and require `isPdfPayload()`;
    otherwise audit, move the row to `rejected`/`not_a_pdf`, answer 415.
- `src/infrastructure/storage/StorageAdapter.ts` — `getObject()` on the port.
- `src/infrastructure/storage/{InMemory,LocalFilesystem}Adapter.ts` — implement it.
- `test/modules/sources/SourceExtractionService.test.ts` +
  `src/modules/sources/__tests__/…` — the two `noopStorage` stubs gained the
  method.
- `contracts/openapi.yaml` — document the content-signature 415 on intake and
  verify; checksum refreshed.
